# Currency Converter

Автор: [Денис Пастухов]

## Описание

Приложение для конвертации валют с графическим интерфейсом, использованием внешнего API и сохранением истории операций.

## Функционал

* Выбор валют для конвертации (из/в).
* Ввод суммы и кнопка конвертации.
* Отображение истории операций в таблице.
* Сохранение истории в файл `history.json`.

## Как получить API‑ключ

1. Перейдите на сайт [exchangerate-api.com](https://www.exchangerate-api.com).
2. Зарегистрируйтесь и получите бесплатный API‑ключ (до 1 500 запросов/месяц).
3. Замените строку `YOUR_API_KEY` в коде на ваш ключ.
